# Job Application Tracker

A full-stack web application for managing and tracking job applications in one place.

## 📌 Overview

The Job Application Tracker helps users keep track of the jobs they have applied for. Users can add, view, update, delete, search, and filter their job applications.

## ✨ Features

- User Registration and Login
- Dashboard with application statistics
- Add new job applications
- Edit existing applications
- Delete applications
- Search applications by company or role
- Filter applications by status
- MongoDB database integration
- Backend REST APIs
- Protected routes
- Responsive user interface
